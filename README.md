Interaktiivne veebileht (Interactive webpage)

1. Mis see on?

Interaktiivne veebileht on siis veebileht, mis sisaldab interaktiivsed UI elemendid, millega käsitlemisel tekitab muudatused veebilehes.

Need muudatused võivad olla kas tausta kui ka teksti värvi muutus, teksti lisamine ja teksti kui ka ui elemendide paigaldamine.

2. Milleks on see tehtud?

Tehtud selleks, et näidata kui sujuvalt on võimalik muudatusi rakendada veebilehele lisades HTML-lile TypeScript-i abi.

2. Mis oli siis kasutatud selle koostmisel?

Selle koostmisel kasutati lihtsalt HTML-i koos Typescriptiga. Samuti, genereeriti JavaScript faili kasutades terminali käsklust npx tsc elements.ts, sest veebileht ei saa lugeda TypeScripti faili.
